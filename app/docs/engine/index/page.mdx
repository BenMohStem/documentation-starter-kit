## The iteration rhythm

Engine work does not proceed by feature list. It proceeds by
numbered iteration, each with the same anatomy: a **design written
before any code runs**, a battery of oracles and armed negative
controls, sanitizers on every build, and a report that states what
was promoted — and what was not. A failed iteration is not a lost
week; it is a mapped wall. The next design walks around it.
