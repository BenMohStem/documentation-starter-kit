Before the engine, the floor: memory, strings, numbers, files,
threads — written by hand, tested adversarially, inherited from
no one.

> An engine that studies memory behavior for a living cannot run on
> a standard library it cannot see inside.

The floor is where the project learned its hardest lessons —
including several bug classes that most codebases never meet,
because the layers beneath them were borrowed rather than owned.

## Why it had to exist

The engine's research line measures memory behavior at the cycle
level — cache lines, prefetch, working sets, first-touch costs.
A borrowed standard library is opaque at exactly the boundary those
measurements cross. When a benchmark shows 548 million cycles spent
on first-touch page faults, the question "whose allocation was
that?" must have an answer.

The floor also keeps the engine honest about portability: written in
plain C against its own layer, the engine carries its environment
with it — the same arithmetic, the same behavior, on every machine
that compiles it.
