# The Plan

<SceneHeader scene="plan" height={230} />

<span className="wwa-page-title">The plan</span>

The world can only be as honest as the engine underneath it.

Most projects build the visible game first and patch the machinery
when it complains. This one inverts the order: prove the machinery,
then let the world arrive on it. The reason is the project's own
history — every time a world system was prototyped early, its real
cost turned out to live in the engine layers below it: memory layout,
broadphase, determinism. Measuring those first is not a detour; it
is the shortcut.

## The order, and why it is not negotiable

Each step earns the next. The physics core cannot be trusted until
the floor beneath it is understood to the byte. The senses cannot be
shared until their cost is measured against each consumer. The living
systems cannot be connected until each survives alone — a food web
that collapses in isolation will collapse louder in company.

The engine research line exists because the plan kept hitting the
same wall: *the simulation's cost is memory traffic*. Where a body
sits in memory changes how fast the solver can think about it. That
single finding reordered the whole roadmap — memory and physics are
now tuned together, not sequentially.

> A step is taken when two things are true: the design cannot proceed
> honestly without it, and the engine can carry it — measured, not
> assumed.
