# Systems

<SceneHeader scene="systems" height={230} />

<span className="wwa-page-title">Systems</span>

A small set of systems that genuinely interact — resources feed
economies, economies feed politics, politics feeds war, war feeds
hunger. Each entry below is the design contract for that system:
what it must do when it arrives, and what it must never fake.

<GlyphCards cards={[

### War & battles

<GlyphCards cards={[
  { glyph: "battle", title: "War emerges", sub: "From resources, territory, politics, trade, revenge, ideology, security — never spawned for spectacle." },
  { glyph: "logistics", title: "Armies are logistics", sub: "Food, equipment, horses, money, manpower — and they march. Never teleport." },
  { glyph: "battle", title: "Personal participation", sub: "Fight, ride, command formations, scout, retreat, negotiate — one participant in a real melee, never a camera." },
]} />

Damage is physical: weapon type, velocity, impact location, armor,
penetration, angle, anatomy. Armor protects the areas it actually
covers. Combat is never artificially safe for balance.

</div>
