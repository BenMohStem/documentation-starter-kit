## Why the order looks backwards

The living systems — ecology, economy, civilization — are the
visible game, and they are being built *last*. That is not caution;
it is the measured lesson of the whole project so far:

- A world system is only as honest as the simulation floor under
  it. Every prototype that skipped the floor had its real cost hiding
  below — in memory layout, in broadphase, in determinism;
- The engine research line found that the simulation's cost is
  dominated by memory traffic — a question that must be answered
  *before* thousands of living entities make it unanswerable;
- Each living system must survive alone before it joins the others.
  A food web that collapses in isolation will collapse louder in
  company.

So the roadmap is a dependency graph, read from the bottom: floor →
physics → shared senses → mechanisms → the world. The Moon is the
top of the ladder because the ladder is real — every rung is
machinery the player can understand, and none of it can be skipped.
