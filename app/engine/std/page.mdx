# Std Layer

<span className="wwa-page-title">The floor</span>

Before the engine, the floor: the standard functions everything else
stands on — memory, strings, numbers, sorting, files, threads —
written by hand and tested adversarially, not inherited on trust.

## Why this is here at all

An engine that studies memory behavior for a living cannot run on a
standard library it cannot see inside. Owning the floor means every
behavior — every allocation, every rounding, every clock tick — is
legible, measurable, and fixable. It also turned out to be an
education: the adversarial test battery has caught subtle bugs in
number formatting, parsing, and subnormal handling that would
otherwise have surfaced years later, deep inside the physics.

## How it is tested

Not by "it seems to work": by designed edge cases — identities held
over tens of thousands of iterations, round-trips through every
conversion, the strange neighborhoods of floating point (±0.0,
subnormals, near-overflow), known-answer vectors, and property-based
sweeps that generate their own cases. Every bug the battery has caught
is kept, with its story, as part of the project's memory — several of
those stories are genuinely humbling, which is exactly why they stay.
