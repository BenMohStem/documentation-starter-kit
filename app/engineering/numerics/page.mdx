## The problem

Floating-point is not associative. `a + b + c` changes result with
reordering; FMA contraction changes it silently in the compiler's hands.
When the solver runs in SIMD lanes, and the layouts rearrange what runs in
which lane, the same physics can produce different bits — unless the
arithmetic tree is part of the contract.

## The contract

1. **The floating-point operation tree is part of the numerical contract.**
   A SIMD solver's lanes must execute a committed operation tree — any
   packet re-formation that changes the tree re-enters the bitwise audit
   (3.168–3.169);
2. **Bitwise lane checks where exactness gates are on**: same input bits in,
   same output bits out, per lane, per packet;
3. **One-packet numerical audit**: every packet shape is audited in
   isolation before it is trusted;
4. **K-cache epochs**: geometric and state epochs invalidate cached solver
   terms exactly — no stale K term survives a topology change undetected
   (the negative controls prove detection).

## Why the game cares

Determinism is the foundation of trust in a world that does not explain
itself: the same river must carve the same valley twice. The replay
harness (70.98x warm-start at zero drift) is only meaningful because the
bits match.
