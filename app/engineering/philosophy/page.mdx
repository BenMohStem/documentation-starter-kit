# Engineering Philosophy

Status: standing law.

The engine is written in C, owns its whole stack, and trusts nothing it has
not measured. This is not asceticism — it is the cost of the game's one
non-negotiable: **a world where consequence is real**.

## The rules

1. **C-first, dependency-light.** The standard library is its own; headers
   stabilized across Windows/MSYS2, Linux, and macOS. The engine builds with
   GCC and Clang, gated by `demo-check`.
2. **Every claim is measured.** A multiplier without its complete-path cost
   is a hypothesis, not a result. Preparation must be paid (3.174).
3. **Stated operator == executed operator.** Source-audited. The benchmark
   text that says one thing while the binary does another is the 3.128
   defect class — extinct here by gate, not by hope.
4. **Error is knowledge.** Failed experiments are preserved, labeled, and
   visible — the [integrity incidents](/research/integrity) page exists
   because this rule exists.
5. **Determinism is a feature.** Same inputs, same world, same bits. Warm
   starts, layout repair, streaming — everything must respect the replay
   contract.
6. **The world sets the workload.** Benchmarks run on the topology
   families, scale, and churn the game will actually produce — never on a
   workload chosen to flatter the code (the 3.186 lesson).

## Why own the stack?

Ten thousand bodies with real friction and stacking; animals whose perception
queries the same grid physics uses; audio that never allocates mid-frame.
None of that is achievable by assembling other people's black boxes and
hoping. Owning the stack is what lets the project measure its own world.

The payoff so far: a solver that replays exactly at 70x warm-start speed, a
spatial foundation serving four engine consumers, and a layout manager that
adapts to the world's own structure — each with its evidence trail.
