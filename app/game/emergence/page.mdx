# Emergence

Emergence is the wager of the whole project: that a small number of
understandable rules, faithfully applied, can produce structures nobody
explicitly scripted.

## What has been measured so far

In deterministic laboratories (the 2.12–2.25 mechanics chain), these
mechanisms were implemented and measured in isolation:

- **Metabolism** — energy in, energy out, cost per action;
- **Regrowth** — resources return on rates, not on respawn timers;
- **Stigmergy** — agents leave signals that change other agents' behavior
  (the ant-path mechanism);
- **Homeostatic drives** — needs that rise, bias behavior, and are satisfied
  by the world, not by UI buttons.

Each was a real program with real measurements. None is a living ecosystem
yet — a lake with fish that behave like fish is still ahead, and we will not
imply otherwise.

## The foundation it will run on

The shared spatial locality layer — one structure serving physics, AI, audio
and rendering consumers through per-consumer masks — is the measured
foundation (integrated host workload ~5.7x vs duplicated grids). When
ecology arrives, thousands of agents will read the same world grid the
physics already uses. No per-agent island universes.

## What has not been shown yet

- An ecosystem that behaves like an ecosystem;
- Societies, economies, or civilizations with believable dynamics.

These are the far milestones of the [roadmap](/game/roadmap). Each will be
promoted only by measurement, never by hope.
