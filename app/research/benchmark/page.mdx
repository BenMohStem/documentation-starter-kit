# Benchmark Doctrine

Status: standing law, earned the hard way.

Every performance claim on this site survives this battery or it does not
appear. The doctrine was built across the 3.x research chain and hardened by
real failures.

## The four validity gates

1. **Mathematical validity** — the stated operator is the executed operator,
   source-audited. A benchmark that measures something other than what its
   text claims is invalid (the 3.128 lesson).
2. **State validity** — an exact-state oracle runs against an independent
   logical reference every frame. Any drift fails the run. A single
   corrupted endpoint must flip the oracle (negative control), or the oracle
   itself is broken.
3. **Measurement validity** — organization, remap, and solve are timed in
   **separate buckets**. Preparation cost is always charged (the 3.174
   lesson: a 4.9x solve speedup that cost 5.2x in preparation is a loss).
   Interleaved policies, min-of-K, explicit noise floors. A claim must
   exceed 2x the measured noise floor.
4. **Workload validity** — the workload must not be trivially optimal for
   the baseline (the 3.186 lesson: an index-local contact builder can never
   test a layout manager). Topology families, scale matrix, churn matrix
   from the benchmark specification.

## Sanitizer gate

ASan + UBSan clean runs (Windows host builds under WSL2 Debian gcc). A
promotion without a sanitizer pass does not exist.

## Instrument validity — the probe audit (3.189)

Any measurement instrument — a probe, a trigger, a classifier — must pass
a **confusion matrix over all workload families** before it can gate a
policy claim. The 3.189 chain probe was caught false-firing on grids and
hubs by exactly this audit, *before any policy timing existed*; the
corrected rule re-passed 5/5 on every family. Predictions are
pre-registered so a miss is a finding, not a tuning opportunity.

**The scale-scope law**: instrument constants are scale-dependent. At 4K
bodies the articulated segment length (8) collides with the hub threshold
(8) in the repetition table and the probe false-fires. Every registration
is scoped to its validated scales — the current probes claim nb ≥ 32768
and nothing below it.

## Reproducibility gate

Fresh processes, repeated, medians and spreads reported. This gate caught
incident 3.185-1 — a promoted result that was pure noise. The gate stays.

## The vocabulary

Every experiment ends in one of: **FOUNDATION / PROMOTED / CANDIDATE /
RESEARCH ONLY / NOT PROMOTED / REJECTED / INVALIDATED / SUPERSEDED** — and
the decision is written down, with its numbers, in the same session.
