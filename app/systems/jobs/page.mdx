## Jobs

- A work-stealing job system sized to the machine, with frame phases that
  respect determinism: parallel execution, deterministic commit order;
- The 6.7x-classic lesson: parallelism claims in this project always carry
  the complete-path cost — scheduling overhead, synchronization, and the
  serial fractions — measured, not assumed.

## Memory

- **Arena discipline**: hot-path allocation happens in arenas with
  predictable lifetime; the per-frame working set is a first-class metric;
- **Access-domain layout**: bodies, contacts, and packets live in
  SoA/AoSoA layouts chosen by how the solver actually sweeps them — the
  subject of the live [layout research](/research/layout);
- **Deterministic replay** requires allocator behavior to be replayable:
  allocation order is part of the world's determinism contract.

## The philosophy

Memory is not a resource to be managed after the fact — it is the
performance model. The engine treats **where data lives** as a
first-class design decision, which is exactly what the layout-manager
research formalizes.
