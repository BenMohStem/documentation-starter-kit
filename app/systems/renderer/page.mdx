## The lesson kept visible

The **interior-SIMD negative result**: an attempt to vectorize tile
interiors measured slower than the scalar path — the memory pattern fought
the layout. The failure is preserved in the project's records because it
defines the rule: renderer optimizations are admitted only when they beat
the reference on the target workload, with complete-path cost charged —
the same law as the solver's.

- The M3 consolidation: renderer, audio, IO, jobs all on the one
